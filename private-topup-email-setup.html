Activar los correos de clases y pagos

Nuevas tarifas: sigue la actualización de correos y calendario para aplicar los precios de septiembre de 2026.

Esta configuración se hace una sola vez con la cuenta de Google que ya administra tus correos y calendario.

Los reportes y las recargas funcionan en la web. Los correos esperan a que completes estos pasos. No necesitas activar Blaze ni contratar otro servicio.

Si ya instalaste los avisos: copia el código actualizado y reemplaza todo el contenido de privateTopupEmails.gs en Google. Guarda. El activador existente cada 15 minutos seguirá funcionando; no necesitas crear otro. Esta versión añade un aviso para ti y otro para el estudiante por cada reserva o reprogramación, con fecha, hora, duración y el enlace de clase disponible. Conserva los avisos de pagos, solicitud y activación.

1. Abre tu proyecto de Google

Entra en Google Apps Script y abre el proyecto que ya usas para Spanish with Elkin, donde está el código de los correos de pago o la sincronización del calendario.

2. Añade el archivo de avisos

En el editor, pulsa + → Secuencia de comandos. Llámalo privateTopupEmails. Borra el ejemplo vacío de ese archivo nuevo y pega el contenido que copia este botón. Conserva los archivos existentes.

Ver el código o copiarlo manualmente

Descargar el archivo

3. Activa el envío

Guarda el proyecto. En el selector de funciones de la parte superior, elige sweInstallPrivateTopupEmails y pulsa Ejecutar. Completa la autorización de Google con la misma cuenta. No hace falta crear una nueva implementación web.

Si aparece un error de acceso a Firestore, verifica que elegiste el proyecto de Apps Script que ya utiliza tu integración y comparte el mensaje del error para revisarlo.

4. Comprueba el estado

Vuelve a Administración → Privadas. En Nuevos pagos de clases aparecerá la configuración de correo para hello@spanishwithelkin.com y la última comprobación.

Se revisarán los avisos aproximadamente cada quince minutos. Tú recibirás los reportes; el estudiante recibirá su acuse y, tras tu revisión, la confirmación o el mensaje de corrección. Informar un pago nunca acredita clases por sí solo.

Si se agota el cupo de correo de Google, los avisos quedan en espera y se reintentan. Un envío cuyo resultado sea incierto requiere revisión para evitar enviar el mismo correo dos veces.
